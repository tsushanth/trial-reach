# Research log

This is the single running record of the research, kept so that no session loses the train of thought. It is written for
whoever picks the work up next, human or assistant.

Rules for this log:

- Read [DATA_POLICY.md](../../DATA_POLICY.md) first. Aggregates only: counts, rates, intervals. No identifiers, no paths, no
  links to data, no personal information, no excerpts of source records.
- Record what was tried, what happened, what was decided and why, including failures and corrections.
- Date every entry. Do not rewrite history; add a dated correction instead.
- Update [00-status.md](00-status.md) at the end of every working session.

Contents:

- [00-status.md](00-status.md): where things stand now and what is next
- [01-arc.md](01-arc.md): how the project got here, in order
- [02-decisions.md](02-decisions.md): decisions with reasons
- [03-mistakes-and-corrections.md](03-mistakes-and-corrections.md): what went wrong and how it was fixed
- [04-data-landscape.md](04-data-landscape.md): which kinds of data exist, what is open, what is gated
- [05-gap-scan.md](05-gap-scan.md): the 2026-10-22 survey of research questions and the novelty checks
- [findings/](findings/): results so far, one file per line of work
